
# Hydration Reminder App

## Lab 06 - Mobile Application Development

In this lab session, we developed a Hydration Reminder App using React Native and Expo.

### Features

- **Reminder Screen:** Allows users to enter a custom reminder message and set a time interval to receive water-drinking reminders.
- **Local Notifications:** Uses `expo-notifications` to schedule repeating notifications and cancel scheduled reminders.
- **Tips Screen:** Displays the benefits of drinking water, such as improving skin health, regulating body temperature, flushing body waste, and maintaining blood pressure.
- **About Screen:** Provides information about the application and the technologies used.
- **Tab Navigation:** Uses Expo Router to navigate between Reminder, Tips, and About screens.

### Technologies Used

- React Native
- Expo
- Expo Router
- TypeScript / TSX
- Expo Notifications

### Conclusion

Through this lab session, we learned how to create a multi-screen mobile application, implement tab navigation, manage user input using React Hooks, and schedule local notifications using Expo.
